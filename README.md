# Task API

A simple Task Management REST API built with FastAPI and SQLite.

This project started as an in-memory CRUD API and was migrated to use SQLite as persistent storage.

---

## Project Description

The Task API provides CRUD operations for managing tasks.

Each task contains:

- `id` — unique task identifier
- `title` — task title
- `done` — whether the task is completed

The API uses:

- **FastAPI** for building the REST API
- **SQLite** for persistent data storage
- **Uvicorn** as the ASGI server
- **Pydantic** for request validation

## Installation

### 1. Clone the repository

```bash
git clone <https://github.com/Ibrahimhussein711/to-do-api/commits/main/>
```

Then move into the project directory:

```bash
cd to-do-api
```

### 2. Create a virtual environment

Windows:

```bash
python -m venv .venv
```

### 3. Activate the virtual environment

PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Command Prompt:

```cmd
.venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install fastapi uvicorn
```

## Database

The project uses SQLite as its database.

The database file is:

```text
tasks.db
```

The database contains a `tasks` table.

---

## Database Schema

The `tasks` table contains:

| Column | Type | Description |
|---|---|---|
| `id` | INTEGER | Unique task ID |
| `title` | TEXT | Task title |
| `done` | INTEGER | Task completion status |

The `id` column is the primary key and is automatically generated by SQLite.

The `done` column uses:

```text
0 = False
1 = True
```

# API Endpoints

## 1. Get All Tasks

### Request

```http
GET /tasks
```

### Example Response

```json
[
  {
    "id": 1,
    "title": "Study Backend",
    "done": false
  },
  {
    "id": 2,
    "title": "Go to Gym",
    "done": true
  }
]
```

### Status Code

```text
200 OK
```

---

## 2. Get Task By ID

### Request

```http
GET /tasks/{id}
```

### Example

```http
GET /tasks/1
```

### Example Response

```json
{
  "id": 1,
  "title": "Study Backend",
  "done": false
}
```

### Status Code

```text
200 OK
```

If the task does not exist:

```text
404 Not Found
```

Example:

```json
{
  "detail": "Task not found"
}
```

---

## 3. Create a New Task

### Request

```http
POST /tasks
```

### Request Body

```json
{
  "title": "Learn FastAPI"
}
```

The `done` value is automatically set to:

```text
false
```

The task ID is generated automatically by SQLite.

### Example Response

```json
{
  "id": 4,
  "title": "Learn FastAPI",
  "done": false
}
```

### Status Code

```text
201 Created
```

---

## 4. Update a Task

### Request

```http
PUT /tasks/{id}
```

### Example

```http
PUT /tasks/1
```

### Request Body

```json
{
  "title": "Study SQL",
  "done": true
}
```

### Example Response

```json
{
  "id": 1,
  "title": "Study SQL",
  "done": true
}
```

### Status Code

```text
200 OK
```

If the task does not exist:

```text
404 Not Found
```

---

## 5. Delete a Task

### Request

```http
DELETE /tasks/{id}
```

### Example

```http
DELETE /tasks/3
```

### Successful Response

```text
204 No Content
```

There is no response body for a successful delete.

If the task does not exist:

```text
404 Not Found
```

# SQL Operations

The API uses SQL queries to communicate with SQLite.

### Select all tasks

```sql
SELECT * FROM tasks;
```

### Select completed tasks

```sql
SELECT * FROM tasks
WHERE done = 1;
```

### Count tasks

```sql
SELECT COUNT(*) FROM tasks;
```

### Insert a task

```sql
INSERT INTO tasks (title, done)
VALUES (?, ?);
```

### Update a task

```sql
UPDATE tasks
SET title = ?, done = ?
WHERE id = ?;
```

### Delete a task

```sql
DELETE FROM tasks
WHERE id = ?;
```

Parameterized queries are used to safely pass values to SQL statements.

# Architecture

The application separates the API layer from the database layer.

```text
Client
  |
  v
FastAPI
  |
  v
main.py
  |
  v
database.py
  |
  v
SQLite
  |
  v
tasks.db
```

### Request Flow Example

```text
POST /tasks
      |
      v
FastAPI endpoint
      |
      v
create_task()
      |
      v
INSERT INTO tasks
      |
      v
SQLite
      |
      v
tasks.db
```
